# Перенос в ServiceDesk-Lite.1 и подготовка к миграции на Neon

## Что произошло

Опубликованное состояние проекта перенесено из репозитория `ServiceDesk-Lite`
(ветка `claude/servicedesk-lite-stage-1-hzf7vf`, HEAD `67d09de`) в уже
существующий репозиторий `ServiceDesk-Lite.1` с сохранением полной
Git-истории (все коммиты этапов 1–4).

Дальнейшая разработка ведётся только в `ServiceDesk-Lite.1`.

## Remotes рабочей копии

| Remote | Назначение |
| --- | --- |
| `origin` | `ServiceDesk-Lite.1` — целевой репозиторий, сюда идёт вся новая разработка |
| `upstream-supabase` | `ServiceDesk-Lite` — исходный репозиторий, доступен только для чтения истории, push в него не выполняется |

## Что входит в этот подготовительный commit

- Имя пакета в `package.json`/`package-lock.json` приведено к
  `servicedesk-lite.1`.
- В README добавлено описание переноса и ссылка на этот документ.
- Создан этот документ миграции.

## Что НЕ входит в этот commit

Функциональная замена Supabase на Neon **не выполнялась**. Аутентификация,
доступ к данным, RLS/RPC и вся бизнес-логика по-прежнему работают поверх
Supabase, как описано в основном README и в
[`docs/database.md`](./database.md) / [`docs/security.md`](./security.md).
Собственно миграция на Neon — предмет отдельной последующей работы.
